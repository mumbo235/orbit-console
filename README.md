# ORBIT

A console-style home screen for the web: a tile row, function bar, quick menu, trophies,
generative music, built-in games, and an App Store of ~100 web apps — all controllable with
keyboard, mouse or a gamepad.

**Live demo:** https://mumbo235.github.io/fakes4/ (browser version)

## Run it

**Desktop app (recommended)** — every web app opens right on the console:

```bash
npm install
./start.sh              # or: ./start.sh --fullscreen
```

**In a browser** — open the live demo above, or `index.html` locally. Sites that block embedding (YouTube, Gmail…) open in a new tab instead.

## Controls

| Input | Action |
|---|---|
| Arrows / D-pad / stick | Move |
| Enter / Space / A | Select |
| Esc / Backspace / B | Back · close app |
| Esc twice (inside a web app) | Back to home |
| Q / F1 / Home button | Quick menu |
| F11 | Fullscreen (desktop app) |

## What's inside

- **Home** — tile row, info cards, function bar (notifications, App Store, trophies, profile, settings, power)
- **Internet Browser** — address bar, bookmarks, history
- **App Store** — ~100 web apps and games, search, categories, or add any URL as your own app
- **Games** — Drift, Serpent, Breaker, Pairs, Skyline
- **Ambience** — endless synthesized background music
- **Settings** — themes, sound, profile/avatar, web app management, system options
- **Trophies** — bronze to platinum, with levels

Brand icons from [Simple Icons](https://simpleicons.org) (CC0), stored in `icons/`.
